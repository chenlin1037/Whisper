在原有功能基础上，完成了「收藏 / 置顶」等功能增强，并对整体架构进行了分层重构，使 ViewModel 更聚焦于 UI 状态与数据组织，业务逻辑统一下沉到 Manager / Service 层，便于后续单元测试与维护。
---
## 功能变化概览
- **声音收藏**
  - 声音卡片右上角新增收藏按钮，支持一键收藏 / 取消收藏。
  - 首页顶部分类栏新增「收藏」分类（有收藏时显示），点击可快速查看收藏声音。
  - 搜索结果中的声音同样支持收藏，状态与首页保持一致。
- **混合置顶**
  - 混合卡片新增「图钉」按钮，支持置顶 / 取消置顶。
  - 混合列表排序规则：**置顶混合优先，其次按最近更新时间倒序**。
- **睡眠定时**
  - 定时器逻辑抽离为独立 Service，保持原有 UI 行为不变。
  - 结束时统一通过 `AllSoundManger` 暂停所有声音。
---
## 分层设计
当前架构分为四层：
1. **View（SwiftUI 视图）**
2. **ViewModel（UI 状态 + 数据组织）**
3. **Manager / Service（业务逻辑）**
4. **Store（持久化）**
